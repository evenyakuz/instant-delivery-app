## ✨ Features

- **📦 Infinite product feed** from all city stores
- **🏪 Store selection** with category filtering
- **⚡ Express delivery** in 15 minutes with guarantee
- **🛒 Multi-store ordering** in one delivery
- **📅 Regular order planning**
- **🎨 Dark/Light theme**
- **🌍 Multilingual** (English/Russian)
- **💳 Fixed delivery cost** (no markup on goods)

## 🚚 Unique Services

- **Rental of goods** (electronics, clothing)
- **Group orders** (shared purchases)
- **Pre-order items** for future dates
- **Express delivery** with priority courier
- **Combined delivery** from multiple stores

## 🛠 Technologies

- **React 18** with Hooks
- **Material-UI 5** for components
- **React Router 6** for navigation
- **Context API** for state management
- **@mui/x-date-pickers** for date handling
- **CSS-in-JS** for styling

## 📦 Installation & Setup

```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/instant-delivery-app.git
cd instant-delivery-app

# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
